## 通用叙事

主文图按“结论推进”排序：

> 队列与可信图谱 → 关键差异 → 核心细胞状态 → 空间生态位 → 互作/调控机制 → 临床与功能验证 → 总体模型

每幅图只承担一个主结论；同一幅图的面板应共同回答一个科学问题。

## 各主图职责

### Figure 1：研究设计与全景图谱

**问题**：研究对象和数据是否足以描述目标系统？

建议面板：

- A：队列、分组、配对、平台和分析流程。
- B：样本/患者元数据与 QC。
- C：全细胞 UMAP/空间域总览。
- D：细胞类型 marker dot/heatmap。
- E：每样本细胞组成或空间域组成。
- F：主要组间总体差异。

不要把所有下游结果提前塞入流程图。

### Figure 2：疾病或治疗相关的关键细胞群

**问题**：谁最能解释主要表型？

- 样本级差异丰度。
- 关键大类的亚聚类与可靠注释。
- 状态/功能评分及 pseudobulk DE。
- 正交原位验证或独立数据集复现。

结尾应锁定一个核心状态，而不是留下十个同等候选。

### Figure 3：关键状态的生物学程序与动态

**问题**：核心细胞为什么特殊，如何形成？

- 差异基因与通路。
- 元程序/调控因子。
- 真实时间、疾病阶段或拟时序动态。
- 关键基因沿轨迹/阶段变化。
- 如有 TCR/BCR、ATAC、CNV 或多组学，用于增强来源/调控证据。

### Figure 4：空间定位与生态位

**问题**：核心状态在哪里，与谁相邻？

- H&E/病理区域和空间映射。
- 目标状态/marker 的空间分布。
- 距离、邻域、共现/排斥或生态位组成。
- 跨患者汇总统计。
- mIHC/IF/RNAscope/IMC/CODEX 验证。

代表切片必须配套跨样本量化。

### Figure 5：候选通讯或调控机制

**问题**：空间生态位通过什么轴产生表型？

- 通讯网络从全局到候选轴的收敛。
- 配体、受体和下游靶基因在对应细胞中的表达。
- 条件差异与空间邻近。
- 受体细胞功能响应。
- 上游调控因子或反馈回路。

### Figure 6：临床价值与外部验证

**问题**：该状态/生态位是否具有可泛化的临床意义？

- 独立队列 signature/去卷积。
- 分期、严重度、疗效或生存关联。
- 多变量模型、校准和外部验证。
- 基线预测与治疗诱导信号分开。

### Figure 7：功能干预与机制闭环

**问题**：候选轴是否影响目标表型，可否被干预？

- 共培养/条件培养基/迁移/杀伤/成球等功能实验。
- 敲除/阻断/过表达和救援。
- 类器官或动物模型。
- 与标准治疗联用或增敏。
- 最后放机制示意图。

资源有限时可把 Figure 6–7 合并，并降低因果措辞。

## 面板选择

| 信息 | 推荐图 | 不推荐做法 |
|---|---|---|
| 样本级比例 | 点图/箱线/森林图 | 仅堆叠条形图 |
| marker 注释 | dot plot/heatmap + feature plot | 大量单基因小提琴图 |
| 轨迹 | trajectory + gene dynamics + state proportion | 只画 pseudotime UMAP |
| 空间定位 | H&E + feature map + ROI 放大 | 无组织学背景的孤立热图 |
| 邻域 | 细胞图、距离分布、共现矩阵 | 仅 LR 圈图 |
| 通讯 | sender–receiver 聚焦图、ligand-target heatmap | 全网络“毛线球” |
| 临床关联 | effect/CI、KM、ROC/校准 | 只报相关系数或 AUC |
| 机制 | 干预—表型—救援组合 | 只验证表达变化 |

## 排版规则

- A 面板通常回答“做了什么/比较什么”，末面板回答“因此得到什么”。
- 相同细胞类型全篇固定颜色；疾病组、时间点和空间区也固定编码。
- 一幅图中的统计点尽量代表患者/动物，而非海量细胞。
- 主图保留决定性证据；QC、完整 marker、替代参数、次要亚群放补充。
- 每幅图标题直接写结论，例如“SPP1+ 巨噬细胞与 COL11A1+ CAF 形成 T 细胞排斥生态位”，而非“细胞通讯分析”。
- 最终示意图只总结已获证据，不添加未经验证的新箭头。
