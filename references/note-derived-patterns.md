# 来源笔记提炼的研究模式

## 使用说明

本参考由以下两个本地 Obsidian 目录的文献笔记归纳而来：

- `文献阅读/单细胞转录组`
- `文献阅读/空间转录组`

其用途是提供研究设计模式，不替代原始论文、方法文档或正式引文核验。笔记中的具体样本数、阈值、算法和结论在复用前应回查原文。

## 模式 1：临床现象 → 关键细胞 → 分子轴 → 因果验证

在天疱疮、类天疱疮、胆管炎、甲状腺癌及多种肿瘤笔记中反复出现：

1. 临床组织先确认某类细胞浸润或表型与疾病相关。
2. 单细胞亚聚类锁定疾病富集亚群。
3. 通过 DEG、通路、调控因子和通讯收敛到候选分子轴。
4. 原位验证细胞身份、分子表达和邻近关系。
5. 共培养、阻断、敲除/过表达及救援验证功能。

适用于以机制为目标的设计。关键是从无偏发现收敛，而不是从预设基因倒推全部结果。

## 模式 2：阶段/部位连续体

宫颈癌、肝肿瘤、肢端黑色素瘤、前列腺癌及原发—转移研究常使用：

- 正常/邻近 → 早期/原位 → 浸润 → 转移/复发。
- 原发灶 → 器官特异转移灶。
- 肿瘤核心 → 侵袭边缘 → 邻近组织。

分析从组成差异进入恶性/致病状态、轨迹/克隆演化，再用空间边界或多区域采样验证。若样本是横断面的，只能描述“与进展一致的连续变化”，不能自动声称个体内演化。

## 模式 3：治疗响应与耐药生态位

NSCLC、肝癌、GBM 等笔记展示了两个互补问题：

- 治疗前什么状态预测响应？
- 治疗后什么状态被诱导、保留或清除？

最佳设计是响应状态 × 治疗时间的配对结构。常见机制包括 CAF–巨噬细胞屏障、T 细胞排斥、缺氧、TLS 成熟度和耗竭状态。应将基线预测与治疗诱导效应分开建模。

## 模式 4：从细胞亚群升级为空间生态位

系统性硬化症、心肌梗死、银屑病、胶质瘤、NSCLC、胃癌和黑色素瘤笔记共同强调：

1. 单细胞定义细胞状态。
2. 空间去卷积/映射确认位置。
3. 邻域、距离、共现/排斥识别生态位。
4. 生态位结合通路或组织学结构解释功能。
5. mIHC/IF/RNAscope/IMC/CODEX 正交验证。

高价值空间结构包括侵袭前沿、坏死周围、血管周围、TLS、表皮—真皮交界和病损—非病损过渡区。

## 模式 5：状态转换与空间梯度对齐

MDS、纤维化、心肌梗死、胶质瘤和 CAF/TAM 研究常把拟时序与空间梯度配对：

- 单核细胞 → 炎症/修复/免疫抑制巨噬细胞。
- 静息成纤维细胞 → 炎性或肌成纤维状态。
- 祖细胞/早期恶性状态 → 侵袭、EMT、耐药状态。

强设计需要真实时间、空间区带、克隆或实验诱导中的至少一种方向证据；只做拟时序不足以证明来源。

## 模式 6：组织—外周血与免疫受体库

胆管炎、类风湿关节炎等笔记用匹配组织和 PBMC 回答：

- 组织富集亚群是驻留、局部扩增还是外周迁入？
- TCR/BCR 克隆是否跨组织共享？
- 相同克隆进入组织后是否改变状态？

设计上要保留患者内配对，并把克隆共享、功能状态和组织位置联合解释。

## 模式 7：代谢—细胞状态—空间互作

晕痣、口腔癌、CRLM、前列腺癌和髓系研究常见：

1. 基因集评分提示代谢程序。
2. 空间上与目标细胞、死亡/应激或免疫生态位共定位。
3. 代谢组/组织液/血清验证代谢物。
4. 代谢物刺激或通路抑制验证细胞功能。

转录评分不能替代代谢通量或代谢物测量。

## 模式 8：单细胞发现 → bulk/临床转化

多篇笔记将亚群 signature 映射到大型 bulk 队列，用于：

- 外部复现细胞状态。
- 关联分期、严重度、预后和治疗响应。
- 构建风险模型或筛选靶点。

高质量设计先固定 signature，再进入外部队列；应优先验证生物学问题，而不是无约束地组合机器学习算法。

## 模式 9：图表的论证节奏

来源笔记中较完整的文章通常采用：

1. Figure 1：队列、流程、全景图谱。
2. Figure 2：疾病/治疗相关细胞亚群。
3. Figure 3：状态功能、轨迹或调控。
4. Figure 4：空间定位/生态位。
5. Figure 5：关键细胞互作。
6. Figure 6：机制轴与原位支持。
7. Figure 7：临床价值/外部验证。
8. Figure 8：干预实验与模式图。

这是一种逻辑模板，不是固定图数。任何图如果不能回答新问题或推进证据层级，应合并或移至补充材料。

## 常见薄弱点

- 细胞比例只展示合并细胞，不展示患者间变异。
- 以单一算法或相关性筛选“核心基因”。
- 把 spot 内共表达视为细胞直接互作。
- 依赖漂亮的代表切片而缺少跨患者统计。
- 以 pseudotime 推断真实谱系。
- 将公共数据多次重复使用却称为独立验证。
- 预后模型的数据泄漏和缺少外部验证。

使用本技能时主动补足这些薄弱点。
