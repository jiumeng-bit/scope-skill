## 选择规则

每个子问题只选能产生判别性证据的模块。先在本文件确定方法类别；用户点名模块、询问实现方法、结果文件或绘图方式时，必须进一步读取 [method-catalog.md](method-catalog.md)。

- 已知用户主要使用 R：给出一个 R 首选路线，必要时补一个 R 替代。
- 已知用户主要使用 Python：给出一个 Python 首选路线，必要时补一个 Python 替代。
- 未指定语言：给出一个首选路线和另一语言的等价路线；不要把所有可用包都列为必做。
- 同一生物学结论需要稳健性验证时，再增加第二种算法，并说明它是验证而非主分析。
- 包版本和数据库版本仅在用户要求代码、复现或方法学细节时锁定；设计阶段先固定包名、对象类型和输出结构。

## 模块响应格式

对每个具体模块使用以下“分析执行卡”：

| 字段 | 内容要求 |
|---|---|
| 目的 | 一句话说明回答的科学问题 |
| 输入 | 对象、矩阵、元数据和分组变量 |
| R 首选 | 包名 + 核心函数/计算 |
| Python 等价 | 包名 + 核心函数/计算 |
| 结果文件 | 对象文件、统计表、基因集/网络/坐标等中间文件 |
| 可视化 | 能直接生成的主图、补充图和诊断图 |
| 统计/边界 | 生物学重复、模型协变量、参数和结论限制 |

结果文件优先采用可追溯命名，例如 `da_celltype_group.tsv`、`de_pseudobulk_celltype.tsv`、`spatial_niche_abundance.tsv`，不要只写“导出CSV”。

## 基础图谱

| 问题 | 分析 | 主要读出 | 注意 |
|---|---|---|---|
| 数据是否可靠 | QC、环境 RNA、doublet、样本/批次诊断 | 每样本细胞数、基因数、线粒体比例、污染 | 阈值按组织和平台调整 |
| 有哪些细胞 | 聚类、参考映射、marker 与人工审阅 | UMAP、marker dot/heatmap | 不以单一 marker 注释 |
| 恶性细胞是谁 | CNV 推断、肿瘤 marker、病理/突变证据 | CNV heatmap、恶性评分 | CNV 推断不是金标准 |
| 注释是否稳定 | 多参考交叉验证、留一数据集验证 | 一致率、混淆矩阵 | 防止参考偏差 |

## 组成与状态

| 问题 | 首选思路 | 输出 |
|---|---|---|
| 哪类细胞丰度变化 | 样本级比例、组成数据模型、差异丰度模型 | effect size + CI、箱线/森林图 |
| 细胞内哪些基因变化 | 按样本聚合的 pseudobulk DE，或含患者效应的模型 | 火山图、效应量热图 |
| 哪些功能程序变化 | GSEA/GSVA/AUCell/模型化 gene-set score | 通路效应量、样本级评分 |
| 亚群如何命名 | top marker + 已知 marker + 功能程序 + 条件富集 | marker dot plot、命名依据表 |
| 状态是否连续 | 连续评分、元程序/NMF、topic/model-based state | 状态热图、连续坐标 |

先展示样本间分布，再展示所有细胞合并结果。关键比例避免只画堆叠条形图；补充样本级点和置信区间。

## 轨迹与调控

| 问题 | 可用方法类别 | 必要约束 |
|---|---|---|
| 状态转变顺序 | pseudotime、trajectory、RNA velocity | 明确起点依据；做算法/参数敏感性 |
| 时间动态 | longitudinal/time-series model | 优先真实时间而非伪时间 |
| 转录因子程序 | regulon/SCENIC、TF activity、motif | 与表达、ATAC 或 ChIP 证据交叉 |
| 扰动后状态改变 | perturbation response、因果网络模拟 | 作为候选生成，需实验验证 |
| 来源/谱系 | 克隆、遗传条形码、谱系追踪 | 仅拟时序不能证明来源 |

轨迹图应包括：细胞/状态分布、起点理由、关键基因动态、功能模块动态和外部/实验验证。

## 空间分析

### 身份映射

- 单细胞参考到空间：去卷积、label transfer、mapping。
- 同时用 marker 空间表达和组织学结构验证。
- 报告参考缺失、共线细胞类型和分辨率限制。

### 空间域与差异

- 空间聚类/域识别后，由病理图像和 marker 解释域身份。
- 组间比较域比例时以患者/切片为统计单位。
- 可做域内 pseudobulk DE、通路活性和条件交互模型。

### 邻域与生态位

- 邻接图、最近邻距离、共现/排斥、细胞邻域聚类、MISTy 类多视图模型。
- 对比随机置换或条件保持的空间 null model。
- 将邻域定义、半径/邻居数和边界处理写入方法。
- 跨患者寻找可复现生态位，而不是只展示代表切片。

### 空间梯度与边界

- 核心→边缘、坏死→血管、表皮→真皮、病灶→非病灶可使用距离变换、空间轨迹或分段模型。
- 将距离作为连续变量比任意二分更有信息；同时进行阈值敏感性分析。

### 空间图建议

- H&E/病理区标注与空间特征图配对。
- 单个代表切片用于解释形态；汇总图用于跨患者统计。
- 相同颜色映射、方向和比例尺；标明 ROI 与边界。

## 细胞通讯

分四层筛选候选轴：

1. 单细胞表达：发送者表达配体，接收者表达受体。
2. 条件差异：信号在主比较中增强/减弱。
3. 受体响应：接收者出现相符靶基因、通路或表型。
4. 空间支持：发送者与接收者邻近，或 LR 在邻域/边界富集。

可组合：LR 数据库方法、ligand-to-target 方法、差异通讯、空间 LR 共现。至少用一种独立方法或手工生物学核验关键轴。复杂多聚体受体需检查亚基完整性。

## 多组学与临床

| 目标 | 分析路径 |
|---|---|
| bulk 外部验证 | 构建细胞/状态 signature → 去卷积或评分 → 队列复现 |
| 预后/疗效 | 预定义特征 → Cox/逻辑回归 → 混杂校正 → 内部验证 → 外部验证 |
| scATAC/多组学 | peak-gene link、motif/TF activity、联合嵌入；验证调控而非只做共嵌入 |
| TCR/BCR | 克隆扩增、组织共享、亚群共享、克隆状态与抗原特异性 |
| 基因组/克隆 | 突变/CNV、克隆结构与空间区域/细胞状态对齐 |
| 代谢/蛋白组 | 通路评分生成假设，代谢物/蛋白定量和干预确认 |
| 跨物种 | ortholog 映射、状态签名相似性、方向一致性；不强求簇一一对应 |

临床模型需避免：在全数据筛特征后再交叉验证、同一队列既定阈值又验证、仅报告 AUC 不报告校准和临床增益。

## 肿瘤和免疫专项

- 肿瘤状态：恶性确认 → 元程序/状态 → 分期/部位差异 → 空间定位 → 预后/疗效。
- T 细胞：naive/memory/cytotoxic/exhaustion/Treg/Tph/Tfh/Trm 等状态需结合多个 marker 与功能签名。
- 髓系：避免简单 M1/M2 二分；以功能状态、来源线索、空间生态位和动态转换描述。
- CAF：亚群命名需有 marker、功能、空间区室和条件富集四类证据。
- TLS：形态、B/T 细胞共定位、成熟标志和空间结构共同定义。
- 代谢：转录评分只表示潜在活性；关键代谢结论需代谢物、通量或功能实验。

## 统计与敏感性分析

必须报告：

- 效应量、置信区间和多重检验，而不只报告 P 值。
- 配对、重复测量、批次和主要协变量。
- 每组患者/动物数、每样本细胞/spot 数及失败样本。
- 聚类分辨率、marker 集、邻域半径、signature 和阈值的敏感性。
- 关键结果在替代方法、独立队列或留一患者分析中的稳定性。

常见降级方案：

- 空间分辨率不足：从“细胞互作”降级为“区域共现”，再用 mIHC/IF 验证。
- 细胞数少：合并到稳定的大类或用层级模型，避免过细分群。
- 患者数少：定位为探索性研究，减少比较，强调效应量和外部验证。
- 轨迹不稳定：改为状态连续谱和阶段关联，不宣称方向。
