# 问题导向框架

## 目录

- 问题句式
- 主问题树
- 证据层级
- 候选收敛
- 结论措辞

## 问题句式

用以下字段写主问题：

> 在【人群/模型】的【疾病阶段/处理/空间区域】中，【细胞状态或生态位】是否通过【候选过程/分子轴】影响【表型/治疗响应/临床结局】？

如果尚无候选机制，先写发现型问题：

> 哪些可重复的细胞状态或空间生态位最能解释【主要组间差异】，并与【主要结局】相关？

主问题必须指定主要比较、主要对象和主要结局。避免“全面解析”“系统探索”作为唯一目标。

## 主问题树

将研究拆成不超过三个递进子问题：

1. **现象/定位**：变化发生在哪类细胞、哪个状态、哪个区域？
2. **联系/机制候选**：该状态与哪些邻居、信号、调控程序或表型同时变化？
3. **验证/转化**：干预候选轴能否改变表型，或该特征能否预测结局？

每个子问题用六格记录：

| 字段 | 要求 |
|---|---|
| 问题 | 可被数据证伪的问句 |
| 样本/比较 | 写清生物学重复、配对和对照 |
| 方法 | 只列回答该问题所需的方法 |
| 读出 | 比例、效应量、评分、距离、轨迹、结局等 |
| 结论边界 | 该读出最多能支持什么 |
| 下一步 | 仍缺的空间、临床或因果证据 |

## 证据层级

按研究资源选择目标层级，不要把较低层级包装成较高层级：

1. **描述**：存在某细胞/状态/空间域。
2. **差异关联**：组间丰度、表达、通路或位置不同。
3. **时序/空间一致性**：变化沿阶段、时间或空间梯度有序发生。
4. **预测关联**：特征与疾病严重度、治疗响应或生存独立相关。
5. **机制支持**：配体—受体、下游响应、调控网络和原位定位相互一致。
6. **因果干预**：阻断/敲除/过表达/救援改变预期表型。
7. **转化验证**：独立队列、类器官/动物、药物增敏或临床工具复现。

生信为主的课题通常可靠地达到 2–4；要声称“驱动”通常需要 5–6。

## 候选收敛

从宽到窄使用预先声明的门槛：

1. 与主比较相关：在样本级差异丰度、伪批量差异或空间域差异中稳定。
2. 生物学特异：在目标细胞/区域有足够特异性，且不是纯技术或应激信号。
3. 跨层一致：单细胞、空间、组织学或 bulk 至少两层方向一致。
4. 临床相关：与严重度、疗效或结局关联，并考虑主要混杂。
5. 机制可验证：存在明确发送者、接收者、下游表型或可干预节点。
6. 可复现：独立队列、不同算法或正交实验支持。

避免把多个算法取交集本身当作生物学证据。交集只能缩小候选，不能证明正确。

## 结论措辞

| 证据 | 推荐措辞 | 避免措辞 |
|---|---|---|
| 丰度/表达差异 | 富集、降低、相关 | 驱动、导致 |
| 拟时序/RNA velocity | 提示状态转换方向 | 证明细胞谱系 |
| 共定位/距离 | 空间邻近、共现、排斥 | 直接相互作用 |
| LR/网络推断 | 候选通讯轴、预测调控 | 已证实信号传递 |
| 多变量预后 | 独立相关、具有预测潜力 | 临床可用 |
| 阻断与救援 | 支持必要性/通路依赖 | 普遍充分，除非有相应设计 |

## 问题失败信号

- 一个问题需要十余种分析但没有主要终点。
- 分组无法区分疾病、部位、时间与治疗效应。
- 核心候选来自单个样本或代表性切片。
- 结论完全依赖分辨率、聚类参数或某一个数据库。
- 图表只能展示结果，无法说明每幅图回答什么问题。
